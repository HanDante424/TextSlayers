# TextSlayers 캐릭터 고유 스킬 (v0.2)

> 규칙 · 스탯 · 시너지는 [TextSlayers_Concept_v0.2.md](TextSlayers_Concept_v0.2.md). 이 문서는 캐릭터별 스킬만 적는다.
> 장착: 액티브 3 + 패시브 1 을 고유 목록에서 고른다. 코드 미반영.

## 스티움 카터렉 (사용자 확정 2026-11-25)

### 패시브
**어둠의 마나 장벽**
- 웨이브 시작 시 마력의 1000% 만큼 보호막 획득.
- 매초 마력의 20% 만큼 보호막 획득. (사용자 확정 2026-11-25, 기존 10% 에서 상향)
- 스킬 사용 시 마력의 50% 만큼 보호막 획득. (사용자 확정 2026-11-25, 추가) `[해석]` 스티움 본인의 액티브 사용이며 상한 적용.
- 보호막 상한은 마력의 1000%.
- 보호막이 있을 때 자신의 강인함 +20.

**깊은 어둠의 마나**
- 마력의 1000% 만큼 최대 체력 증가. `[임시]` (기존 250% 에서 상향)
- 최대 체력의 1% 만큼 마력 증가. (사용자 확정 2026-11-25, 기존 5% 에서 하향)

**각성 - 어둠**
- 적 처치 시 어둠 흡수 1 획득.
- 스킬을 5회 사용할 때마다 어둠 흡수 1 획득.

### 액티브 (사용자 2026-11-25, 수치는 `[임시]`)
피해는 **물리**(공격력 계수, 방어력 적용)와 **마법**(`고정 값 + 마력 계수`, 저항력 적용)로 나뉜다. 마법의 고정 값이 스킬 기본 피해량(저점 보정)이다.

**회전베기** — 쿨타임 6초
- 기본: 전방위의 적에게 공격력 100% 물리 피해 + (80 + 마력 50%) 마법 피해.
- 어둠 각성: 공격력 100% 물리 + (120 + 마력 125%) 마법. 추가로 4방향 검기가 적중한 모든 적에게 (60 + 마력 75%) 마법 피해.

**강격검** — 쿨타임 12초
- 기본: 대상에게 공격력 150% 물리 피해 + (90 + 마력 60%) 마법 피해.
- 어둠 각성: 공격력 150% 물리 + (160 + 마력 120%) 마법. 추가로 어둠의 파동이 주변 적들에게 (200 + 마력 160%) 마법 피해.

**어둠의 검기** — 쿨타임 10초
- 기본: 검기를 날려 처음 적중하는 적에게 (60 + 마력 75%) 마법 피해.
- 어둠 각성: 부채꼴로 커지는 검기가 적중하는 모든 적에게 (100 + 마력 200%) 마법 피해.

**어둠의 파동** — 쿨타임 11초 (군중제어)
- 기본: 자신으로부터 파동을 일으켜 근처 적을 밀쳐내고 (80 + 마력 60%) 마법 피해. `[해석]` "60%"는 마력 계수.
- 어둠 각성: 근처 적을 밀쳐내고 (110 + 마력 100%) 마법 피해 + 1초 기절. 추가로 모든 적의 이동속도 -20.

### 해석 `[해석]`
- 어둠 각성은 직업 특성 **악마사냥꾼**의 상태다. 어둠 흡수 10 에서 각성하며 전투 종료까지 유지한다. "각성 - 어둠" 패시브는 흡수를 얻는 방법을 늘린다 (마족 처치 시에는 특성 +1 과 패시브 +1 을 모두 받는다).
- "스킬 5회 사용" 은 스티움 본인의 액티브 사용 횟수.
- 깊은 어둠의 마나는 서로를 다시 키우지 않는다: 마력으로 체력을 한 번 올리고, 그 체력으로 마력을 한 번 올린다.
- 공격력 계수 부분은 방어력, 마력 계수 부분은 저항력의 영향을 받는다.

### 미정
- 다른 캐릭터의 기본 체력 · 공격력 · 마력 기준.
- 사거리 · 범위 (전방위 · 근처 · 검기 · 부채꼴의 크기), 밀쳐내는 거리.
- "모든 적의 이동속도 -20" 의 지속시간.

## 스킬 피해 구조 (사용자 2026-11-25)
- 스킬 피해 = **물리**(`공격력 × 계수`, 방어력 적용) + **마법**(`스킬 기본 피해량 + 마력 × 계수`, 저항력 적용). 기본 피해량은 스탯이 낮을 때의 저점 보정용 고정 값이다.
- 7장 규칙의 "고정 피해"(방어 · 저항 · 증폭 무시)와는 **다른 개념**.
- `[해석]` 스킬 기본 피해량은 마법 피해 쪽에 붙으므로 저항력의 영향을 받는다.

## 밸런스 기준 (사용자 확정 2026-11-25, 수치 `[임시]`)
- 스티움 기본 공격 속도 **0.6회/초**. `[해석]` 기본 공격 = 공격력 100% 물리 피해.
- 기준 스탯: **공격력 30, 마력 30, 체력 1500** (스티움 기본 체력, 사용자 확정 2026-11-25, `[임시]`).
- 기준 시나리오 (스킬 세팅 A = 회전베기 · 강격검 · 어둠의 검기 / B = 회전베기 · 어둠의 검기 · 어둠의 파동, 시뮬 가정: 0초에 전 스킬 사용 후 쿨타임마다 반복, 기본 공격 병행):

| 대상 | 세팅 | 기본 상태 처치 | 어둠 각성 처치 |
|---|---|---|---|
| 체력 800, 방어 0 · 저항 0 | A | 약 11.7초 | 0초대 (첫 사용분 약 920) |
| 체력 800, 방어 0 · 저항 0 | B | 11초 | 6초 |
| 체력 1200, 방어 20 · 저항 20 | A | 약 23.3초 | 10초 |
| 체력 1200, 방어 20 · 저항 20 | B | 24초 | 12초 |

- 스킬 1회 피해 (X=30, 방어 · 저항 0): 회전베기 125 (강화 270) / 강격검 153 (강화 489) / 어둠의 검기 82.5 (강화 160) / 어둠의 파동 98 (강화 140).
- 어둠 각성 상태가 매우 강한 것은 **의도**다 (사용자 확정 2026-11-25): 각성 조건(어둠 흡수 10)이 어렵기 때문에 강화 피해를 높게 잡았다. 강화 피해는 이대로 유지.
